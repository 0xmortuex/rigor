Rigor

A browser engine written from scratch in Mort.

What you are looking at

This page was tokenized, parsed into a DOM, cascaded against a user-agent stylesheet and the rules above, laid out into a box tree, and rasterized to the pixels on your screen — by code with no libraries underneath it.

Every stage follows its specification: the HTML tokenizer is WHATWG §13.2.5 state for state, and the CSS side is Syntax Level 3.

Text is drawn with a bitmap font and measured with estimated advances, so it is legible but not metrically accurate. Real font parsing is the next milestone.

Things that work

Nested markup with bold, italic and inline code. Misnested tags are repaired by the adoption agency algorithm. Long paragraphs wrap at the content edge, honour margins and padding, and collapse adjacent vertical margins the way the box model requires.

Backgrounds and borders paint too.
