Links and resizing

Jump to: the middle · the bottom · an external link

Hovering a link turns the pointer into a hand, because the box tree is hit-tested against the cursor and the result walked up to the nearest anchor. Clicking one of the first two scrolls to its target.

Resize the window and this panel changes colour. That is not a repaint trick: the whole cascade re-runs, so the @media (max-width: 700px) rule starts or stops matching, and the layout is rebuilt from the styles it produces.

The middle

Text reflows to the new width at the same time, breaking at the opportunities UAX #14 finds rather than only at spaces, so a long word with hyphens can break after one of them and a run of Chinese can break at all: 中文網頁測試中文網頁測試中文網頁測試中文網頁測試。

An external link does nothing when clicked. Following it would need the network stack, and this program cannot import it: the TLS backend pulls in the Windows headers, which collide with the viewer's own declarations of the same API. The rigor CLI has no such conflict and does fetch.
